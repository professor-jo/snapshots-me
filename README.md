# Snapshots.Me

My personal website, designed like a Jupyter notebook. It covers my projects, tech stack, and career timeline.

**Live: [professor-jo.github.io/snapshots-me](https://professor-jo.github.io/snapshots-me/)**

![Snapshots.Me homepage](docs/preview.png)

- Day and night themes that switch with the visitor's local time
- Works on phones, tablets, and desktops

Built with React, Vite, Tailwind CSS, and Framer Motion. Hosted on GitHub Pages.
